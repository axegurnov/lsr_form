# lsr.form

Модуль Битрикс для приёма заявок на интересующий объект недвижимости (квартиру в доме) с собственным хранилищем данных и админкой — без использования инфоблоков и штатных форм Битрикс.

## Стек

- 1С-Битрикс (Bitrix Framework)
- PHP
- MySQL

## Функционал

Модуль реализует форму со следующими полями:

- Имя
- Почта
- Телефон
- Интересуемый объект недвижимости (квартира)

### Модель данных

- **Дом** — до 100 записей.
- **Квартира** — до 10 000 записей, привязана к дому.
- **Статус квартиры**: `свободна` / `забронирована` / `продана`.
- В выпадающем списке формы доступны только квартиры со статусом `свободна` или `забронирована` — проданные не показываются и не принимаются.

### Логика отправки

- Валидация формата почты и телефона на стороне сервера (и клиента).
- При успешной отправке — ответ `ok`.
- При попытке сохранить дубль по почте или телефону — ошибка: `такая почта/телефон уже есть`.
- Если выбранная квартира уже не свободна (стала проданной между показом формы и отправкой) — ошибка: `Выберите другой объект недвижимости`.

### Админка

В административной части Битрикса добавлен раздел для просмотра заполненных заявок. Реализован собственными средствами модуля (без штатных форм/инфоблоков).

## Структура модуля

```
local/modules/lsr.form/
├── include.php                  # подключение классов модуля
├── install/
│   ├── index.php                # установщик/деинсталлятор модуля
│   ├── version.php              # версия модуля
│   └── db/                      # SQL установки/удаления таблиц
├── lib/                         # классы модуля (D7, namespace Lsr\Form)
├── admin/                       # страницы админки (список заявок)
└── README.md
```

## Установка

1. Скопировать папку `lsr.form` в `local/modules/` вашего проекта.
2. В административной части Битрикса перейти в *Marketplace → Установленные решения*.
3. Найти модуль **lsr.form** и установить его — установщик создаст необходимые таблицы в БД.

## Подключение формы на странице

```php
<?php
\Bitrix\Main\Loader::includeModule('lsr.form');

$APPLICATION->IncludeComponent(
    'lsr:form.request',
    '.default',
    []
);
```

## Просмотр заявок

После установки в админке появится пункт меню со списком заявок. Доступ — по правам модуля (настраиваются в *Настройки → Пользователи → Группы пользователей*).

## Ограничения

- Инфоблоки Битрикс **не используются**.
- Модуль «Веб-формы» Битрикс **не используется**.
- Все сущности (дома, квартиры, заявки) хранятся в собственных таблицах модуля.
